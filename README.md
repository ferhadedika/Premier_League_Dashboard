# Premier League Performance Dashboard

An interactive dashboard of Premier League results from 2020/21 to 2024/25. It compares what happened on the pitch with the underlying numbers behind it, such as expected goals (xG), possession and shots on target, so analysts, coaching staff and fans can see past the scoreline.

The data covers 1,900 matches, 27 clubs and 5 seasons. Every chart responds to the same season, venue, result and club filters.

## Features

- Four views: Executive Overview, Exploratory Analysis, Detailed Investigation, and Story and Insights
- Filters for season, venue, result and club that apply everywhere, saved in the address bar so a view can be shared and the Back button works
- Click any club in any chart to select it, or open its detail page with its form, its numbers against the league and every match
- Command menu with Ctrl K (or Cmd K on a Mac) to jump to a club, view, season or filter
- Light, dark and automatic themes
- Works on phones, with keyboard navigation and screen reader descriptions for every chart
- Story figures are calculated from the data, so they always match it

## Run it

No install or build is needed. Open `Dashboard/premier-league-dashboard.html` in a browser.

## Project structure

```
Dashboard/
  premier-league-dashboard.html   page
  styles.css                      design tokens and styles
  js/                             app code, one file per view (core, overview, explore, detail, story, main)
  data/matches.js                 data file generated from the CSV
  vendor/d3.v7.9.0.min.js         d3 charting library
  img/                            icon images
Data/final_matches_cleaned.csv    source data
Report/                           written reports
tools/
  build-data.py                   rebuilds Dashboard/data/matches.js from the CSV
  check.mjs                       automated checks and screenshots
screenshots/
  pages/                          full page screenshots of every view
  preview/                        images used in this README
```

## Updating the data

Edit `Data/final_matches_cleaned.csv`, then run

```bash
python tools/build-data.py
```

## Checks

`tools/check.mjs` opens the dashboard in headless Chrome or Edge and checks every view and filter combination for errors, layout at desktop and phone widths, colour contrast in both themes, the address bar state and the wording of all visible text. It needs Node 22 or newer and no other installs.

```bash
node tools/check.mjs
```

Add `--shots <folder>` to save full page screenshots of every view.
